# SepticScope launch sequence

1. Connect `patwyclark/septicscope` to Cloudflare Pages.
2. Use branch `main`, build command `python build_site.py`, and output directory `site`.
3. Deploy to the assigned `*.pages.dev` URL.
4. Verify homepage, county pages, FAQs, `robots.txt`, and `sitemap.xml`.
5. Register and attach the final domain.
6. Set `SITE_BASE_URL` to the final HTTPS domain and redeploy.
7. Set up the real corrections/contact mailbox.
8. Verify with Google Search Console and submit `/sitemap.xml`.
9. Add analytics and update the privacy policy to match the provider actually used.
10. Apply for AdSense after the public site has substantive content and stable navigation.
11. After approval, add live ad units and replace the `ads.txt` placeholder.

Expand counties only from primary state/local sources with visible review dates.
